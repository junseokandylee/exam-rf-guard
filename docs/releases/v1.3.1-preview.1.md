# RF 스위퍼 v1.3.1-preview.1

주변 Wi-Fi를 네트워크 이름으로 쉽게 찾고, 채널과 신호 세기를 함께 살펴볼 수 있도록 개선했습니다. README도 수능 부정행위 우려를 계기로 만든 취지와 장비별로 확인할 수 있는 범위부터 설명하도록 다시 썼습니다.

## 달라진 점

- **주변 네트워크 목록:** 채널 탭을 열면 이름(SSID), 주소(BSSID), 채널과 마지막 신호 세기가 먼저 나옵니다. 같은 이름이어도 주소가 다르면 따로 표시하고, 처음·마지막 관측과 숨김 이력을 확인할 수 있습니다.
- **채널·세기 그래프:** 2.4·5·6 GHz별로 최근 관측한 접속점의 주채널과 RSSI를 표시합니다. 이름을 누르면 해당 접속점의 상세로 연결됩니다. 실제 트래픽 혼잡률이나 전파 스펙트럼 측정은 아닙니다.
- **최근과 이력 구분:** 잠깐 보였다 사라진 접속점은 이력에 남습니다. 같은 주소가 채널을 바꾸면 최신 채널을 먼저 결정하므로 대역 필터로 과거 채널이 현재 목록에 다시 나타나지 않습니다. 최신 채널을 결정할 수 없거나 이전 자료에 정보가 없으면 미확정으로 표시합니다.
- **간단한 첫 화면:** 검색·대역·숨김 필터와 긴 설명은 펼쳐볼 수 있습니다. 비교 화면이나 새 채널 알림에서는 채널 비교로 바로 이동합니다.
- **기록 시각 보정:** 탐색 전에는 가짜 날짜 대신 기록이 없음을 표시합니다. 탐색을 다시 시작해도 선택 범위에 포함된 같은 Wi-Fi 주소의 최초 관측과 최대 세기를 유지합니다.
- **Bluetooth 안내:** 수신 화면에서 Bluetooth 채널 관측의 범위를 펼쳐볼 수 있습니다. README는 제3자 연결의 통신, 루팅, 외부 수신기의 차이를 설명합니다. Bluetooth 패킷 감청이나 외부 장비 연동을 추가한 버전은 아닙니다.
- **대중을 위한 설명:** 공유기·핫스팟·이어폰·스마트워치·카메라·LTE/5G 휴대전화·자기유도 수신기 등의 탐지 조건과 한계를 표로 정리했습니다. 설치와 입실 전 저장 → 입실 후 비교 → 추가 신호 확인 순서, 기록 보관과 개인정보도 안내합니다.

## 사용 순서

1. 비교 탭에서 공간 이름을 입력하고 탐색을 시작합니다. 수신 탭에서 결과가 들어오는지 확인한 뒤 비교 화면의 **① 입실 전 저장**을 누릅니다.
2. 같은 공간·같은 위치와 탐색 범위를 유지하며 **② 입실 후 저장하고 비교**를 누릅니다. 추가 신호를 눌러 유형·제조사와 모델 후보·관측 이력을 확인합니다.
3. **채널 → 주변 네트워크**에서 Wi-Fi 목록을 보고 **채널·세기 그래프**를 펼칩니다. 기준과 달라진 주파수는 **채널 비교**에서 확인합니다.

## 첨부·검증

- `rf-sweeper-v1.3.1-preview.1-debug.apk`: Android 10 이상, 기존 프리뷰와 같은 **debug 서명 테스트용 APK**입니다.
- `SHA256SUMS.txt`: APK SHA-256 확인값입니다.
- `QUICKSTART.ko.md`, Wi-Fi 화면 PNG: 실제 Compose 화면을 가상 데이터로 실행한 사용 예시입니다.
- JUnit·Robolectric 단위/Android UI 테스트 **268개 통과**(실패·오류·건너뜀 0), APK 빌드 통과, Lint 오류 0개·경고 21개.

실물 단말의 무선 수신과 실제 시험장의 수신률·누락률·발열·배터리는 아직 검증하지 않았습니다. 추가 신호·숨김 SSID는 부정행위의 증거가 아니며, 결과가 0개여도 금지 장비가 없다는 뜻은 아닙니다. 이미 연결된 다른 두 기기의 Bluetooth 통신을 모두 관측하는 기능은 없고, 루팅만으로 이 제한이 없어지지도 않습니다.
